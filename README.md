# MultasLoader
### sistema para automatizar la generación de reportes y estadisticas de las personas multadas

## Ejecutar el codigo desde VsCode

> [!NOTE]
> Para el desarrollo de este sistema se esta utilizando uv
> 

> [!TIP]
> Si lo quiere ejecutar lo desde codigo
> ```
>   uv run .\src\multasloader\main.py
> ```

> [!IMPORTANT]
> No hay ejecutable hasta los momentos ya que es una versión  muy temprana
